# Archived Architecture Decision Records

> **Related documents**
>
> - ADR index: [`../README.md`](../README.md)
> - Decision map: [`../decision-map.md`](../decision-map.md)

Every ADR in this folder has the status Superseded. It records what was decided and why at the time;
it is not a current rule. Each file names the ADR that replaced it in its `Superseded by` line.

Read one when you need the history of a decision. Do not implement from one, and do not cite one as
the reason for new code. If an archived ADR and the code disagree, the code and the superseding ADR
are right.

When an ADR becomes Superseded, set its status, fill in `Superseded by`, and move it here with
`git mv` in the same change. Links from other documents keep working because they are rewritten to
this folder.
